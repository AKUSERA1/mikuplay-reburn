# MikuPlay Reburn

面向移动端的 MMD（MikuMikuDance）3D 场景创作与视频渲染工具。将 `PMX`/`PMD`/`BPMX` 模型与 `VMD` 动作相结合，打造属于你的动画视频。

## 核心功能

### 模型与动作

- **多格式导入** — 支持 PMX、PMD、BPMX 模型文件，以及 VMD 动作与镜头动画
- **多模型同屏** — 同时加载多个模型和动作，一键播放所有动画
- **镜头动画** — 独立的 VMD 镜头轨道，与模型动画精确同步
- **骨骼控制** — 可视化选择任一骨骼，实时移动、旋转、缩放，支持骨骼旋转角度校正
- **形态编辑** — 自由调节模型表情 Morph 权重
- **骨骼父级绑定** — 实验性跨模型骨骼绑定，将一个模型的骨骼跟随另一个模型运动

### 场景与渲染

- **实时画面预览** — 60 FPS 流畅渲染，支持双指旋转/缩放/平移操作
- **分辨率选择** — 支持原始分辨率、720P、1080P、2K 输出
- **实时录制** — 所见即所得，一键录制屏幕画面
- **离线渲染** — 帧级精确渲染至 MP4 视频，支持自定义帧率和码率，输出稳定不掉帧
- **音频合成** — 渲染时自动同步背景音乐，输出完整视听作品
- **偏色修复** — 针对部分 Android 设备视频偏色问题提供一键修复开关

### 世界与照明

- **光照调节** — 环境光、方向光实时参数调整
- **后期特效** — 泛光（Bloom）、景深（DOF）、色彩分级滤镜，支持创建自定义预设
- **天空盒** — 环境贴图与程序化天空背景
- **网格地面** — 可开关的参考网格，辅助空间定位
- **背景控制** — 自定义背景色、导入媒体背景

### 物理与粒子

- **MMD 物理模拟** — 头发、裙摆等刚体物理，支持重力调整和精度控制
- **粒子系统** — 内置雨、雪、樱花等预设效果，自由调节参数

### 着色系统

- **材质预设** — 提供多个可调整参数，两种着色分支
- **自定义着色器** — 插件化的材质适配器，支持安装第三方着色器插件
- **纹理降采样** — 可选纹理优化以提升低端设备性能

### 性能与优化

- **内建性能监测** — 实时 FPS 与帧时间显示，默认开启
- **物理精度控制** — 可调节子步数与更新频率，平衡精度与性能

### 插件系统

- **安装第三方插件** — 支持 `.mkp` 格式插件包，扩展软件功能
- **统一管理** — 侧面板插件列表，一键启用/禁用/更新/卸载

## 平台支持

- 最低 Android 12（API 31）
